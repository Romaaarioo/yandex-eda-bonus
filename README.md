# Бонус — калькулятор для курьера

Небольшое веб-приложение для планирования бонусных смен Яндекс Еды. Считает, сколько времени займёт цель, сколько выйдет за период и какая получится реальная ставка в час. Учитывает доступные часы по каждому дню, проверяет выполнимость цели и считает средние по реальным сменам. Ниже показывает погоду на выбранные даты.

**Живая версия:** [romaaarioo.github.io/yandex-eda-bonus](https://romaaarioo.github.io/yandex-eda-bonus/)

## Запуск

```bash
cd "D:\Open Code\yandex_eda"
npm start
```

Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173).

Можно открыть и просто `index.html`, но для загрузки прогноза лучше запускать через локальный сервер. Зависимостей нет — нужен только Node.js.

## Как считается

По умолчанию:

- 1,5 заказа в час;
- 200 ₽ базовая оплата за час;
- 8 часов в день в плане, максимум — 12 часов.

Формулы:

- нужные часы = цель по заказам ÷ заказы в час;
- доступные часы = сумма часов по всем дням периода;
- базовая оплата = отработанные часы × 200 ₽;
- бонус начисляется, только если доступных часов хватает на цель;
- итог = базовая оплата + бонус;
- реальная ставка = итог ÷ отработанные часы;
- средний заработок в час = сумма заработка ÷ сумма часов по реальным сменам.

Блок «График по дням» показывает каждый день периода с датой и днём недели. Часы можно задать вручную или кнопками 8 / 10 / 12 ч. Если плана не хватает, приложение покажет дефицит часов, число дополнительных дней и сколько часов нужно добавить в день.

Блок «Реальные смены» принимает строки в формате `заработок часы` или `заработок часы заказы` (разделитель — пробел, дробная часть — запятая или точка). Кнопка «Подставить в расчёт» переносит среднюю ставку в допущения, а при наличии заказов — и средние заказы в час.

Допущения можно изменить в блоке «Допущения расчёта». Даты, цель, бонус, часы по дням и данные смен сохраняются в `localStorage`.

## Погода

- Город: посёлок Зональная Станция (Томская область), координаты `56.42995, 85.01547`.
- Источник: [Open-Meteo](https://open-meteo.com/). Это бесплатный API без ключа, который отдаёт те же параметры: температуру, «ощущается как», ветер, вероятность и количество осадков.
- Показываются утро (9:00), день (14:00) и вечер (19:00) по местному времени Томска.
- Прогноз доступен на 16 дней вперёд. Для более дальних дат карточки показывают заглушку.
- Данные кешируются в памяти на 30 минут.

Почему не напрямую Яндекс Погода: у Яндекса нет открытого API без ключа, а страница погоды не предназначена для прямых запросов из браузера (CORS и защита от парсинга). Open-Meteo выбран как надёжный источник с такими же погодными параметрами.

## Ограничения

- Максимальная длина периода — 31 день, максимум — 12 часов в день.
- Погода отображается только в пределах доступного окна прогноза.
- Заказы в час нельзя вычислить из заработка и часов: для этого в строках смен нужно указать количество заказов. Без них заказы в час остаются допущением.
- Налоги, комиссии и возможные штрафы не учитываются.
- Приложение не является официальным сервисом Яндекс Еды.
